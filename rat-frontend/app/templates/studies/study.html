LLM Setup & Connection Guide

The Universal LLM Classifier uses the OpenAI-compatible API standard. This allows you to connect almost any AI model in the world—either running locally on your hardware (free and private) or via cloud providers.

Running free local models via Ollama & ngrok

Ensure Ollama is installed and running on your machine. You must pull a model first (e.g., run ollama run llama3 in your terminal).

Remote Connection Required: Because this platform is hosted remotely, it cannot read localhost directly from your browser. You must bridge your local Ollama port to the web using a secure tunnel like ngrok.
  1. Configure Ollama: Set your machine's environment variable to OLLAMA_HOST=0.0.0.0 and restart the Ollama application to allow external traffic.
  2. Start ngrok: Download ngrok, add your authtoken, and run the following command in your terminal:
    ngrok http 11434 --host-header="localhost:11434"
  3. Copy the Tunnel URL: Grab the public forwarding URL provided by the ngrok terminal window (e.g., https://abcd-123.ngrok-free.app).
  • API Base URL https://<your-ngrok-url>/v1
    Note: If RAT is running inside Docker, use http://host.docker.internal:11434/v1 or your host IP. Otherwise, use your ngrok URL. The /v1 at the end is mandatory!
  • API Key Leave this field blank. Ollama does not require authentication.
  • Model Identifier llama3.2:latest (or gemma4:26b, gpt-oss:20b)
Connecting to Cloud APIs (OpenRouter, Groq, OpenAI, etc.)

The Universal LLM tool supports any platform that uses the OpenAI API standard. This includes aggregators like OpenRouter, lightning-fast LPUs like Groq, or generic OpenAI/DeepSeek endpoints.

  • API Base URL (Examples)
    • OpenRouter: https://openrouter.ai/api/v1
    • Groq: https://api.groq.com/openai/v1
    • Together AI: https://api.together.xyz/v1
    • OpenAI: https://api.openai.com/v1
  • API Key sk-...
    Generate this key in the developer console of your chosen provider.
  • Model Identifier llama3-8b-8192 (Depends completely on the provider)
    Check your provider's documentation for the exact model string. OpenRouter usually requires an author prefix (e.g. meta-llama/llama-3-8b-instruct).
